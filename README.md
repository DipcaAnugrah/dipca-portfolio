# Dipca Anugrah — Portfolio

Personal portfolio for Dipca Anugrah, a digital problem solver and AI-assisted developer. Built with Next.js, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment

Copy `.env.example` to `.env.local` when a hosted cashier demo URL is available:

```env
NEXT_PUBLIC_CASHIER_DEMO_URL=https://your-demo-url.example
```

## Checks

```bash
npm run lint
npm run build
```
